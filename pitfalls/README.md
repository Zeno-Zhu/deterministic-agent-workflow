> **AI 请勿通读本目录。** 本目录属于冷存层（`C`）。
> 入口是 `pitfalls/INDEX.md`（一行一坑，唯一默认可读项）。
> 命中后**只读那一行指向的 `PNNN-*.md`**，其余一律不读。

## 本目录放什么

- 本 skill（`workflow-skill-builder`）自己踩过的坑的**完整复盘**：现象 / 根因 / 最小解决方案 / 已排除项。

## 为什么留档

- 它是本 skill 教出去的「三级递进」机制的**活样板** —— 抄列格式、抄卡片结构都从这里抄；
- 也是**反污染的证据**：每条坑先在这里躺够命中次数，够格才准进 `SKILL.md`。

## 清理条件

命中 ≥3 次且已晋升进 `SKILL.md` 的条目，正文可继续留档对照；
**判定为「本机 / 本项目专属」的条目必须移出本目录**，改写进环境文档或项目文档。

## 保留策略

| 项 | 值 |

| 保留量 | 无上限，但 `INDEX.md` 超 40 行就归档已晋升项 |
