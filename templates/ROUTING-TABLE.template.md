## 列定义（不要改列）

| 列 | 填什么 |
|---|---|
| `渠道` | 人类可读的渠道名；弃用的加 `历史` 前缀 |
| `触发词` | 用户**实际会说的**词：正式名、口语简称、旧名、平台名、模型名各种拼写 |
| `子 skill` | **真实存在的同级 skill 名**（死路由会被校验脚本判错） |
| `关键差异` | ★ 写**能力形态**（按次计费 / 时长固定 / 不能传音频 / 要先传图床），**不写数值**。作用是帮 AI 选，不是替 AI 执行 |
| `协议文档` | 该渠道协议文档路径（一渠道一份，禁止混装） |

## 匹配顺序

1. 精确命中触发词 → 直连。
2. 只命中域关键词、没点名渠道 → 走默认渠道并**显式声明**。
3. 点名了未收录的渠道 → 告知不在册，询问是否走默认；**不要猜**。
4. 多个触发词冲突 → 按上表**行序**取第一个，并说明命中了哪条。
