## 列定义（不要改列）

| 列 | 填什么 |
|---|---|
| `ID` | `PNNN`，递增，**永不复用**（复用会串历史） |
| `一句话现象` | 可被搜索匹配的**原话**，不要写根因（根因在正文里） |
| `命中` | 同一坑每再出现一次 **+1** |
| `处置` | `备案` / `已晋升` / `降级`（降级=不可通用，已移出 Skill） |
| `详情` | 备案填文件名；已晋升填 `SKILL.md §<小节>`；降级填去向 |
| `通用化` | `✅ 一类操作` / `❌ 项目或本机专属` / `⏳ 待判` |

## 维护动作

- 新增坑：正文照 `templates/PITFALL-CARD.template.md` 写 → 本表加一行。
- 再踩同一坑：`命中` +1；若 ≥3 且通用且可执行 → 改 `处置` 为 `已晋升`，把通用规则写进 `SKILL.md`。
- 晋升后：**同时检查有没有能删掉的旧条目**（只增不减的 Skill 会烂）。
- 本表 > 40 行 → 已晋升项归档，只留未晋升。
