# <domain>-creation · 中控

> **本 skill 只做路由。** 任何渠道的参数、计费、字段、报错特征、坑，一律不在本文件出现 ——
> 它们属于对应的渠道 skill。规则见 `references/multi-platform-routing.md`。

## 默认渠道

**默认 = <渠道名>。** 用户未点名平台时走它，**并在回复里显式声明"本次走 <渠道名>"**。
用户点名渠道 → 直连该渠道，不比较、不推荐。

## Load First

1. `references/routing-table.md` —— 路由表（**唯一权威**）
2. `references/shared-contract.md` —— 跨渠道公共约定（仅在本文件不够用时）

> ⚠ 按路由结果**只加载那一条渠道 skill**。其余渠道 skill **一个字都不读**。

## 路由流程

```text
读用户需求 → 在路由表匹配触发词
            ├─ 命中 → 加载该渠道 skill → 交给它执行
            ├─ 点名了未收录的渠道 → 告知不在册，问是否走默认
            └─ 未点名 → 走默认渠道，显式声明
```

## 工作区硬规则

- 先识别目标项目目录，并在其中创建新的任务文件夹。
- 所有输入引用、中间产物、状态、日志和最终交付物都写入该任务文件夹。
- Skill 目录只保存可复用能力，绝不承载 live task 的运行数据。
